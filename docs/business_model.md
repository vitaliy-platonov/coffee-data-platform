# Coffee Data Platform — Бизнес-модель

## 1. Бизнес-контекст

Coffee Data Platform моделирует операционные данные сети кофеен.

Бизнес работает с несколькими магазинами, клиентами, сотрудниками, продуктами, поставщиками, заказами, платежами и поставками.

Платформа объединяет эти данные в единую аналитическую систему.

## 2. Основные бизнес-сущности

Основные сущности предметной области:

- категории продуктов;
- поставщики;
- магазины;
- клиенты;
- продукты;
- сотрудники;
- заказы;
- позиции заказов;
- платежи;
- поставки.

## 3. Основные бизнес-процессы

### Продажи

Клиент оформляет заказ в магазине.

Заказ связан с:

- клиентом;
- магазином;
- сотрудником;
- датой заказа;
- общей суммой.

Каждый заказ может содержать несколько позиций продуктов.

### Оплата

Для заказа фиксируется информация об оплате:

- дата платежа;
- способ оплаты;
- сумма;
- статус.

### Управление продуктами

Продукты относятся к категориям и связаны с поставщиками.

Для продукта хранится цена и основная информация о товаре.

### Управление магазинами

Каждый магазин имеет:

- название;
- адрес;
- регион;
- дату открытия;
- статус активности.

Сотрудники закреплены за магазинами.

### Поставки

Поставки связывают:

- поставщика;
- магазин;
- продукт;
- количество;
- дату поставки.

## 4. Бизнес-цели аналитической платформы

Платформа предназначена для подготовки данных для анализа:

- продаж;
- выручки;
- среднего чека;
- клиентов;
- продуктов;
- магазинов;
- количества заказов;
- количества проданных товаров;
- эффективности отдельных магазинов.

## 5. Аналитические MARTS

На основе Data Warehouse формируются следующие аналитические наборы:

### Sales MART

Анализ продаж по дате и магазину.

Основные показатели:

- количество заказов;
- выручка;
- средний чек.

### Customer MART

Анализ клиентов.

Основные показатели:

- количество заказов;
- общая сумма покупок;
- средний чек.

### Product MART

Анализ продуктов.

Основные показатели:

- количество заказов;
- количество проданных единиц;
- выручка продукта.

### Store MART

Анализ магазинов.

Основные показатели:

- количество заказов;
- количество клиентов;
- общая выручка;
- средний чек.

## 6. Результат для бизнеса

Платформа преобразует операционные данные в структурированные аналитические наборы, которые могут использоваться для бизнес-анализа и визуализации в Power BI.
